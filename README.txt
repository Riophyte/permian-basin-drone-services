PERMIAN BASIN DRONE SERVICES — WEBSITE PREVIEW

How to preview on a computer:
1. Unzip this folder.
2. Double-click index.html.

For the best preview (especially local video playback), run a simple local server from the folder:
- Windows with Python installed: python -m http.server 8000
- Mac with Python installed: python3 -m http.server 8000
Then open http://localhost:8000 in a browser.

Publishing options:
- GitHub Pages
- Cloudflare Pages
- Netlify

The quote form currently opens the visitor's default email app with the form contents pre-filled. This avoids needing a paid backend. A hosted form service can be added later if desired.

Main files:
- index.html — content and structure
- styles.css — layout and visual design
- script.js — navigation, filtering, lightbox, email form
- assets/ — photos, logo and videos
